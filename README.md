# Convertisseur de dimensions

Outil HTML autonome pour convertir des dimensions entre millimètres, centimètres et pixels.

Fonctions :
- conversion mm / cm / px ;
- résolution native et résolution effective ;
- agrandissement en % façon Photoshop ;
- calcul cible ;
- calcul de trame selon PPP :
  - intervalle de ligne ;
  - lignes par mm ;
  - lignes par cm.

## Preview

La version en ligne est disponible via GitHub Pages :

## Utilisation

Ouvrir simplement `index.html` dans un navigateur.
